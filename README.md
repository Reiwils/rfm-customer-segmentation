# 🛒 Customer Segmentation Using RFM Analysis

## 📌 Project Overview
Project ini bertujuan untuk melakukan segmentasi pelanggan dari *Online Retail Dataset* menggunakan metode RFM (Recency, Frequency, Monetary). Analisis ini digunakan untuk memisahkan pelanggan ke dalam kategori seperti *Loyal Customers*, *Potential Loyalist*, dan *At-Risk Customers*.

## 🛠️ Tech Stack Used
* **Database:** MySQL 
* **Programming Language:** Python 
* **Environment:** Jupyter Notebook
* **Data Visualization:** Matplotlib, Seaborn

## 📂 Dataset
Dataset yang digunakan dalam project ini adalah **Online Retail Dataset** yang berisi transaksi e-commerce. Karena keterbatasan ukuran, dataset tidak disertakan di repositori ini. 
Kamu dapat mengunduhnya secara langsung melalui: (https://www.kaggle.com/datasets/ulrikthygepedersen/online-retail-dataset)

## 💡 Business Recommendations (Actionable Insights)
* **🏆 Champions:** Berikan akses awal untuk produk baru dan program poin loyalitas premium. Jangan gunakan diskon besar.
* **🌟 Potential Loyalist:** Tawarkan promo *bundling* atau diskon ongkos kirim minimum belanja untuk meningkatkan frekuensi pembelian (*Upselling*).
* **⚠️ At-Risk Customers:** Kirimkan kampanye email personal dengan penawaran waktu terbatas untuk menarik mereka kembali sebelum mereka *churn*.

## 🚀 How to Run This Project
1. Clone repositori ini.
2. Buat database di MySQL dan import dataset.
3. Copy file `.env.example` menjadi `.env` dan isi kredensial MySQL-mu.
4. Jalankan `RFM_Analysis_Segmentation.ipynb`.
